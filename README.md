# سیستەمی حیساباتی دووکانی جوملە

بەرنامەیەکی **تەواو سەربەخۆ** بۆ دووکانی جوملە — لەسەر کۆمپیوتەرەکەی خۆت
کاردەکات، بەبێ ئینتەرنێت و بەبێ ئەکاونت.

| فایل | داتابەیس |
|---|---|
| `golden_shop.py` | `~/OilShopAccounting/oil_shop.db` |

---

## بەشەکان

| بەش | کارەکەی |
|---|---|
| داشبۆرد | فرۆشتن، قەرزەکان، بەهای مەخزەن، قازانج |
| فرۆشتن | پسووڵە، داشکاندن، پارەی دراو، هەناردەی PDF |
| کڕیاران | قەرزی خۆکار، وەرگرتنی پارە، کەشف حساب |
| مەخزەن | کاڵاکان، کڕین، ئاگاداری کەمبوون |
| مەسروفات و مووچە | خەرجی و کارمەندان |
| ڕاپۆرت | قازانجی خاو و سافی، باشترین کاڵاکان، CSV |

> تێچووی هەر کاڵایەک لە کاتی **کڕین**دا دەنووسیت. قازانج لەسەر ئەو تێچووە
> حیساب دەکرێت.

---

## جێبەجێکردن (بۆ گەشەپێدان)

```bash
pip install -r requirements.txt

python golden_shop.py
```

پێویستە Python 3.10 یان نوێتر دامەزرابێت.

---

## درووستکردنی فایلی EXE

لەسەر **ویندۆز** دوو جار کلیک لە `build.bat` بکە. دوو فایل درووست دەکات:

```
dist\OilShopAccounting-Setup.exe    ← دامەزرێنەر
dist\OilShopAccounting.exe          ← سەربەخۆ (بێ دامەزراندن)
```

**دامەزرێنەرەکە** لە کاتی دامەزراندندا تیکێک پیشان دەدات بۆ درووستکردنی
**شۆرتکەت لەسەر دێسکتۆپ**، و لە `Add or remove programs` دەردەکەوێت.

بۆ دامەزرێنەرەکە پێویستە [Inno Setup](https://jrsoftware.org/isinfo.php) دامەزرابێت:

```
winget install JRSoftware.InnoSetup
```

ئەگەر دانەمەزرابێت، `build.bat` تەنها فایلە سەربەخۆکە درووست دەکات.

ئایکۆنەکە (`shop.ico`) بە `make_icons.py` دەنەخشێندرێت — `build.bat` خۆی
بانگی دەکات، بۆیە پێویست ناکات جیا جێبەجێی بکەیت.

> **گرنگ:** فایلی EXE ی ویندۆز تەنها لەسەر ویندۆز درووست دەبێت.

## وێبسایتەکە

`index.html` لەسەر **GitHub Pages** بڵاو دەکرێتەوە
(**Settings → Pages** ، برانچ `main` ، فۆڵدەر `/ (root)`).

دوگمەی داگرتن ئاماژە بۆ **دوایین Release** دەکات، بۆیە دوای هەر وەشانێکی نوێ
پێویست ناکات `index.html` بگۆڕیت — تەنها Release ـێکی نوێ بڵاو بکەرەوە و
هەمان ناوی فایل (`OilShopAccounting-Setup.exe`) بەکاربهێنە.

## باکئەپ

لە **ڕێکخستن** فۆڵدەرێکی هاوبەش یان کلاود هەڵبژێرە.
هەر جارێک بەرنامەکە دادەخرێت کۆپییەک دەنێردرێت و ٢٠ باکئەپی دواتر هەڵدەگیرێن.

ناوی فایلی باکئەپ: `oil_shop_<بەروار>.db`

هەروەها لە هەمان بەش دەتوانیت **شوێنی داتابەیس** بگۆڕیت — بۆ نموونە بۆ
فۆڵدەرێکی نێتوۆرک، ئەگەر چەند کۆمپیوتەرێک هەمان داتا بەکاربهێنن.

> **ئاگاداری:** لە یەک کاتدا دوو کەس داتا تۆمار نەکەن لەسەر فۆڵدەرێکی
> هاوبەشی کلاود — دەکرێت گۆڕانکارییەکان لەناو بچن.
