# دوو سیستەمی حیسابات

دوو بەرنامەی **تەواو سەربەخۆ**، هەریەکە داتابەیسی خۆی هەیە و
بەبێ ئەوەی تر کاردەکات.

| فایل | بۆ چی | داتابەیس |
|---|---|---|
| `golden_shop.py` | دووکانی جوملە | `~/OilShopAccounting/oil_shop.db` |
| `golden_factory.py` | کارگەی ڕۆن | `~/FactoryAccounting/factory.db` |

---

## سیستەمی دووکان

| بەش | کارەکەی |
|---|---|
| داشبۆرد | فرۆشتن، قەرزەکان، بەهای مەخزەن، قازانج |
| فرۆشتن | پسووڵە، داشکاندن، پارەی دراو، هەناردەی PDF |
| کڕیاران | قەرزی خۆکار، وەرگرتنی پارە، کەشف حساب |
| مەخزەن | کاڵاکان، کڕین، ئاگاداری کەمبوون |
| مەسروفات و مووچە | خەرجی و کارمەندان |
| ڕاپۆرت | قازانجی خاو و سافی، باشترین کاڵاکان، CSV |

> تێچووی هەر کاڵایەک لە کاتی **کڕین**دا دەنووسیت. قازانج لەسەر ئەو تێچووە
> حیساب دەکرێت.

## سیستەمی کارگە

| بەش | کارەکەی |
|---|---|
| داشبۆرد | بەهای مەخزەن، بەرهەمی مانگ، تێچوو، دەرچوو |
| مەخزەن | مادەی خام و بەرهەم بە جیا |
| بەرهەمهێنان | مادە + مووچە + تێچووی گشتی ← تێچووی یەک یەکە |
| دەرچوون | بەرهەمی دەرچوو لە کارگە، بڕ لە مەخزەن کەم دەکاتەوە |
| مەسروفات و مووچە | خەرجی و کرێکاران |
| ڕاپۆرت | تێچووی بەرهەمهێنان، مادەی بەکارهاتوو، CSV |

---

## جێبەجێکردن (بۆ گەشەپێدان)

```bash
pip install -r requirements.txt

python golden_shop.py       # سیستەمی دووکان
python golden_factory.py    # سیستەمی کارگە
```

پێویستە Python 3.10 یان نوێتر دامەزرابێت.

---

## درووستکردنی فایلەکانی EXE

لەسەر **ویندۆز** دوو جار کلیک لە `build.bat` بکە. چوار فایل درووست دەکات:

```
dist\OilShopAccounting-Setup.exe    ← دامەزرێنەر
dist\FactoryAccounting-Setup.exe    ← دامەزرێنەر
dist\OilShopAccounting.exe          ← سەربەخۆ (بێ دامەزراندن)
dist\FactoryAccounting.exe          ← سەربەخۆ (بێ دامەزراندن)
```

**دامەزرێنەرەکان** لە کاتی دامەزراندندا تیکێک پیشان دەدەن بۆ درووستکردنی
**شۆرتکەت لەسەر دێسکتۆپ**، و لە `Add or remove programs` دەردەکەون.

بۆ دامەزرێنەرەکان پێویستە [Inno Setup](https://jrsoftware.org/isinfo.php) دامەزرابێت:

```
winget install JRSoftware.InnoSetup
```

ئەگەر دانەمەزرابێت، `build.bat` تەنها فایلە سەربەخۆکان درووست دەکات.

> **گرنگ:** فایلی EXE ی ویندۆز تەنها لەسەر ویندۆز درووست دەبێت.
> ئەگەر ئایکۆنت هەیە، فایلێکی `logo.ico` بخە ناو هەمان فۆڵدەرەوە.

## بڵاوکردنەوەی وێبسایتەکە (GitHub Pages)

١. ڕیپۆیەکی نوێ درووست بکە و هەموو فایلەکان push بکە.

٢. بڕۆ بۆ **Settings → Pages** ، لە بەشی *Source* هەڵبژێرە
   `Deploy from a branch` ، برانچ `main` و فۆڵدەر `/ (root)` .

٣. دوای چەند خولەکێک سایتەکە لەسەر ئەم لینکە دەردەکەوێت:
   `https://<ناوی-ئەکاونت>.github.io/<ناوی-ڕیپۆ>/`

### دانانی فایلەکانی EXE

**ئەگەر لە ١٠٠MB کەمترن** — هەردوو فایل بخە پاڵ `index.html` لە ڕیپۆکە.
دوگمەکانی داگرتن خۆیان کاردەکەن.

**ئەگەر لە ١٠٠MB زیاترن** — بیانخە سەر **Releases**:

- بڕۆ بۆ **Releases → Create a new release**
- تاگێک بنووسە (نموونە `v1.0`) و هەردوو فایل بار بکە
- پاشان لە `index.html` لینکەکانی `OilShopAccounting.exe` و
  `FactoryAccounting.exe` بگۆڕە بۆ لینکی Release ـەکە

## باکئەپ

لە **ڕێکخستن** فۆڵدەرێکی هاوبەش یان کلاود هەڵبژێرە.
هەر جارێک بەرنامەکە دادەخرێت کۆپییەک دەنێردرێت و ٢٠ باکئەپی دواتر هەڵدەگیرێن.

هەر سیستەمێک باکئەپی جیاواز درووست دەکات:
`oil_shop_<بەروار>.db` و `factory_<بەروار>.db`

هەروەها لە هەمان بەش دەتوانیت **شوێنی داتابەیس** بگۆڕیت — بۆ نموونە بۆ
فۆڵدەرێکی نێتوۆرک، ئەگەر چەند کۆمپیوتەرێک هەمان داتا بەکاربهێنن.

> **ئاگاداری:** لە یەک کاتدا دوو کەس داتا تۆمار نەکەن لەسەر فۆڵدەرێکی
> هاوبەشی کلاود — دەکرێت گۆڕانکارییەکان لەناو بچن.
