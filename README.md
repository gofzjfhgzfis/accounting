# سیستەمی حیساباتی دووکانی جوملە

بەرنامەیەکی **تەواو سەربەخۆ** بۆ دووکانی جوملە — لەسەر کۆمپیوتەرەکەی خۆت
کاردەکات، بەبێ ئینتەرنێت و بەبێ ئەکاونت. بە **Dart و Flutter** نووسراوە.

| ئامێر | داتابەیس |
|---|---|
| ویندۆز ١٠ / ١١ | `~/OilShopAccounting/oil_shop.db` (SQLite) |

---

## بەشەکان

| بەش | کارەکەی |
|---|---|
| داشبۆرد | فرۆشتن، قازانج، قەرزەکان، بەهای مەخزەن، چارتی فرۆشتن |
| فرۆشتن | پسووڵە، فرۆشتن بە سکانی بارکۆد، کڕیاری نەقد، داشکاندن، چاپکردن و PDF، گەڕان و فلتەر |
| کڕیاران | قەرزی خۆکار، وەرگرتنی پارە، کەشف حساب بە ماوەی هەر هەنگاوێک |
| مەخزەن | کاڵاکان، جۆر، بارکۆد و چاپی لەیبڵ، کڕین (نەقد یان قەرز)، ئاگاداری کەمبوون |
| دابینکەران | قەرزی دابینکەران، دانی پارە، کەشف حساب، مێژووی کڕین |
| مەسروفات و مووچە | خەرجی، کارمەندان، مووچەی مانگانە |
| ڕاپۆرت | قازانجی خاو و سافی، چارت، باشترین کاڵا و کڕیاران، PDF و CSV |
| ڕێکخستن | زانیاری دووکان، قفڵی ژمارەی نهێنی، باکئەپ، شوێنی داتابەیس |

> تێچووی هەر کاڵایەک لە کاتی **کڕین**دا دەنووسیت. قازانج لەسەر ئەو تێچووە
> حیساب دەکرێت.

**کورتەڕێگاکان:** `Ctrl+N` یان `F2` پسووڵەی نوێ (ئامادە بۆ سکان) · `Ctrl+1…8` گۆڕینی بەش · `F5` نوێکردنەوە

## پێکهاتەی کۆد

| فۆڵدەر / فایل | ناوەڕۆک |
|---|---|
| `lib/main.dart` | دەستپێکردن، قفڵ، یەکەم کردنەوە، پەنجەرەی سەرەکی و کورتەڕێگاکان |
| `lib/core/` | داتابەیس (`db.dart`)، ڕێکخستن، ژمارە و بەروار، بارکۆدی Code 128 |
| `lib/ui/` | ڕەنگ (تاریک / ڕووناک)، کارت، خشتە، چارت، دیالۆگ، زمانی کوردی |
| `lib/print/` | پسووڵە، کەشف حساب، ڕاپۆرت و لەیبڵ — PDF و چاپکردن |
| `lib/pages/` | هەشت بەشەکە: داشبۆرد، فرۆشتن، کڕیاران، مەخزەن، دابینکەران، مەسروفات، ڕاپۆرت، ڕێکخستن |
| `integration_test/` | تاقیکردنەوەی تەواوی بەرنامەکە لەسەر ویندۆز |
| `windows/` | پڕۆژەی ویندۆزی Flutter (ناو، ئایکۆن، قەبارەی پەنجەرە) |

> **PDF و پیتی کوردی:** پسووڵە و ڕاپۆرتەکان بە Flutter خۆی دەنەخشێنرێن و وەک
> وێنە دەخرێنە ناو PDF ـەوە، چونکە پاکێجی PDF هەموو پیتە کوردییەکان
> (ڕ، ڵ، ێ، ە) بە دروستی پێکەوە نابەستێت.

## بارکۆد

- **سکانەر:** هەر سکانەرێکی USB کە وەک کیبۆرد کاردەکات. لە «فرۆشتن» هەر سکانێک
  دانەیەک لە کاڵاکە دەخاتە سەر پسووڵە.
- **کاڵای بێ بارکۆد:** لە فۆرمی کاڵادا «درووستکردن» ژمارەیەکی ١٢ ڕەقەمی دەدات
  کە بە `2` دەست پێدەکات، تا لەگەڵ بارکۆدی کۆمپانیاکان تێکەڵ نەبێت.
- **چاپی لەیبڵ:** لە «مەخزەن» ← «چاپی بارکۆد»: پەڕەی A4 (٢٤ یان ٤٠ لەیبڵ) یان
  پرینتەری لەیبڵ (٥٠×٣٠ یان ٤٠×٢٥ mm). جۆری بارکۆد Code 128 ـە.
- ئەگەر کیبۆردی کوردی چالاک بێت و ژمارەکان وەک `١٢٣` بێن، بەرنامەکە خۆی
  دەیانگۆڕێت بۆ `123`.

داتابەیسی وەشانە کۆنەکان خۆکارانە نوێ دەکرێتەوە — هیچ داتایەک لەناو ناچێت.

## جێبەجێکردن (بۆ گەشەپێدان)

پێداویستییەکان:

- [Flutter](https://docs.flutter.dev/get-started/install/windows/desktop) (stable)
- Visual Studio لەگەڵ **Desktop development with C++**
- **Developer Mode** لە ڕێکخستنی ویندۆزدا چالاک بێت

```bash
flutter pub get

flutter run -d windows
```

تاقیکردنەوە (بە داتای فۆڵدەرێکی جیا، تا داتای ڕاستەقینە دەستی لێ نەدرێت):

```bash
set OILSHOP_HOME=C:\temp\shop-test
flutter test integration_test -d windows
```

## درووستکردنی دامەزرێنەر

لەسەر **ویندۆز** دوو جار کلیک لە `build.bat` بکە. بەرنامەکە درووست دەکات و
پاشان دامەزرێنەرەکە:

```
build\windows\x64\runner\Release\      ← بەرنامەکە و فایلەکانی
dist\OilShopAccounting-Setup.exe        ← دامەزرێنەر
```

**دامەزرێنەرەکە** لە کاتی دامەزراندندا تیکێک پیشان دەدات بۆ درووستکردنی
**شۆرتکەت لەسەر دێسکتۆپ**، و لە `Add or remove programs` دەردەکەوێت.
فایلەکانی Visual C++ لەگەڵ بەرنامەکەدان، بۆیە لەسەر هەر ویندۆزێک کاردەکات.

بۆ دامەزرێنەرەکە پێویستە [Inno Setup](https://jrsoftware.org/isinfo.php) دامەزرابێت:

```
winget install JRSoftware.InnoSetup
```

## وێبسایتەکە

`index.html` لەسەر **GitHub Pages** بڵاو دەکرێتەوە
(**Settings → Pages** ، برانچ `main` ، فۆڵدەر `/ (root)`).

هەمان ناوی فایل (`OilShopAccounting-Setup.exe`) بەکاربهێنە.
